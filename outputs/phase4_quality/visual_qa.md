# 산출물 시각·파일 검수 (2026-09-09)

- 그림 11종의 PNG를 직접 열어 확인했다. 300dpi PNG와 대응 SVG를 함께 저장했다.
- 01 구성, 02 유효성, 03 원자료 승자 참고, 04 지표 관계, 05 장애물 조건,
  06 수렴성, 07 검증 사례, 08 도달 실패/충돌의 두 그림, 09 목적별 다른 선택,
  10 로봇·이동 조건을 확인했다.
- 한글은 Malgun Gothic, 일부 수학 지수는 DejaVu Sans 폴백으로 표시한다.
  초기 누락된 지수 문자를 수정했고, J 가로축 눈금 겹침을 줄였다.
- 링크 비율 그림의 라벨을 실제 원자료 정의(짧은 링크/긴 링크)에 맞췄다.
  방향 있는 L1/L2 조건은 별도 계산한 파생량이다.
- 도달 실패 사례의 빈 피적분함수 영역에 '계산하지 않음, 0 아님'을 표시하고
  시간축을 0~T로 고정했다. 시작·도착과 도달 불가 표본을 표시했다.
- 모든 곡선 색을 고정했고, 수렴성 그림에도 곡선 범례와 상황·후보 수를 넣었다.
- Excel 7개 시트 전체의 첫 화면, 긴 표의 끝부분을 렌더링하여 직접 확인했다.
  비율 수식 열의 정렬을 수정하고, 요약 시트에 no_valid_candidate 원인을 추가했다.
- 표본 전체/긴 수식을 Excel에 밀어 넣지 않았다. 수식 원본은 JSON, 표 원본은 CSV다.
- 24개 비율 수식을 재계산했다. 도달 후보 수를 일시적으로 절반으로 바꾸어 비율도
  절반이 되는 것을 확인하고 원래 값을 복원한 뒤 내보냈다.
- 수식 오류 검색 결과 0건. 실제 XLSX XML의 수식 수·오류 셀·캐시 숫자를
  원본 요약표와 대조했다. CSV·PNG DPI·SVG 문서·XLSX 검증은 artifact_checks.csv 참조.
- 검수는 저장 파일과 렌더러를 사용했다. 네이티브 Microsoft Excel 앱에서 직접
  조작·인쇄 시험은 하지 않았으므로, 프린터별 페이지 나눔까지 보증하지 않는다.

렌더링 중 발견한 문제는 분석 내용이나 사전 수치 허용 기준을 바꾸지 않고 수정했다.
Excel은 spreadsheets 스킬의 작성·재계산·렌더링·내보내기 절차에 따라 제작했다.
