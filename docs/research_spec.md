# 2관절 로봇팔 경로 탐구 — 0~2단계 연구 명세

## 연구 질문

1. 끝점에서 짧은 곡선이 관절 공간에서도 항상 효율적인가?
2. 팔 길이와 시작·도착 위치에 따라 실행 가능한 곡선 계열이 어떻게 달라지는가?
3. 이후 장애물 조건까지 포함할 때 어떤 특징이 최적 곡선 계열을 결정하는가?

## 현재 모델

- 2차원 평면 위의 고정 밑부분 2R 로봇팔
- 링크 길이: `L1 > 0`, `L2 > 0`
- 관절: 회전관절 2개
- 끝점 경로: `p(t) = (x(t), y(t))`, `0 ≤ t ≤ 1`
- 역기구학: 팔꿈치 위/아래 두 가지 해를 별도로 계산
- 현재 링크 두께, 질량, 중력, 관절 제한, 장애물은 포함하지 않음

## 도달 가능 영역

밑부분에서 끝점까지의 거리를 `r`이라 하면 다음을 만족해야 한다.

```text
|L1 - L2| ≤ r ≤ L1 + L2
```

경로의 시작점과 도착점뿐 아니라 샘플링된 모든 점에 이 조건을 적용한다.

## 역기구학

밑부분을 원점으로 옮긴 끝점 좌표를 `(x, y)`라 할 때:

```text
cos(theta2) = (x² + y² - L1² - L2²) / (2 L1 L2)
theta1 = atan2(y, x) - atan2(L2 sin(theta2), L1 + L2 cos(theta2))
```

`sin(theta2)`의 부호로 팔꿈치 위/아래 해를 구분한다. 경로를 따라 각도를 계산한 후 `2π` 경계에서 생기는 불연속을 보정한다.

## 2단계 곡선 계열

- 직선
- 원호
- 3차 베지어
- 3차 에르미트
- 아핀 변환된 사이클로이드 한 주기
- 극방정식 `r = a + b cos(phi)`에서 선택한 리마송 구간의 닮음변환

모든 곡선은 동일한 시작점과 도착점을 갖도록 정규화하고 매개방정식으로 저장한다.

## 현재 검증 범위

- 순기구학과 역기구학 왕복 오차
- 작업 영역 안/밖 판정
- 두 역기구학 해의 존재
- 경로 중 도달 불가능한 점의 위치
- 각 곡선의 시작·도착점 일치
- 원호의 반지름 일정성
