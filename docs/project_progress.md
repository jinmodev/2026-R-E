# Robot Path Lab 진행 기록

기준일: 2026-10-21. 이 문서는 단계별 구현과 완료 기록 및 다음 단계 계획을 구분해 정리한다.

## 연구 목표

여러 매개곡선을 2차원 2관절 로봇팔의 끝점 경로로 사용하고, 로봇 밑부분·링크 길이·시작점·도착점·장애물에 따라 어떤 경로가 적합한지 수학적으로 탐구한다. 향후 데이터를 기반으로 평가기준별 및 종합 최적 후보를 추천하고, 곡선 방정식과 관절각 합성식까지 출력하는 앱으로 확장한다.

핵심 질문은 “어떤 곡선이 항상 최고인가?”보다 “어떤 조건과 평가기준에서 선택이 달라지는가?”이다. 현재의 최적은 정의된 42개 후보 중 최적이며, 모든 가능한 곡선의 전역 최적을 뜻하지 않는다. 3차원 확장은 장기 아이디어이며 현재 구현 범위는 2차원 2R이다.

## 현재 GUI

- 직선, 원호, 3차 베지어, 3차 에르미트, 사이클로이드, 리마송을 선택한다.
- 밑부분 좌표, 두 링크 길이, 끝점 시작·도착점, 굽힘값, 팔꿈치 해, 이동시간을 입력한다.
- 여러 원형 장애물을 추가·삭제하고 두 링크의 자세와 충돌을 확인한다.
- 재생·일시정지·처음으로·시간 슬라이더·재생 속도를 제공한다.
- 곡선식, theta1(t), theta2(t) 합성식과 관절각 그래프를 표시한다.
- 현재 실행의 수식·지표·시간표본을 JSON/CSV로 내보낸다.

경로에 도달 불가능한 구간이 있으면 전체 관절 운동을 정의할 수 없어 관련 적분값에 `—`가 표시될 수 있다. 경로 자체의 길이와 곡률 지표는 계산 가능하다. 장애물이 없을 때 접근 벌점은 0이며 최소 장애물 여유는 빈값이다. GUI는 사용자가 선택한 경로 하나를 평가하며 자동 추천은 아직 제공하지 않는다.

## Phase 4 수학 모델

끝점 경로는 p(u)=(x(u),y(u)), 0≤u≤1이다. 기본 이동시간 T=3초와 공통 진행률 u(t)=10(t/T)^3−15(t/T)^4+6(t/T)^5를 적용한다. 이 진행률을 합성했다고 모든 관절 궤적의 저크가 최소화되는 것은 아니다.

밑부분을 뺀 상대 좌표 X(t), Y(t)로 역기구학을 계산하고, 팔꿈치 해와 각도 unwrap 정책을 보존한다. theta(t)는 임의 다항식으로 회귀하지 않고 곡선·시간함수·역기구학의 합성식과 수치 표본으로 저장한다.

| 기호 | 적분 | 용도 |
|---|---|---|
| L | ∫₀¹ √(x′²+y′²) du | 경로 길이 |
| Eθ | ∫₀ᵀ (θ̇₁²+θ̇₂²) dt | 관절 운동 노력도; 실제 J 단위 에너지 아님 |
| A | ∫₀ᵀ (θ̈₁²+θ̈₂²) dt | 각가속도 보조 지표 |
| J | ∫₀ᵀ (θ⃛₁²+θ⃛₂²) dt | 각저크 비용 |
| Kε | ∫₀¹ (x′y″−y′x″)²/(x′²+y′²+εᵥ²)^(5/2) du | 정칙화 곡률 비용 |
| O | ∫₀ᵀ 1/max(c(t),εc)² dt | 두 링크와 장애물 사이 최소 여유 기반 접근 벌점 |

유효 후보들 안에서 다섯 핵심 비용을 시나리오별 최소–최대 정규화한다. 가중치는 L 0.25, Eθ 0.20, J 0.20, Kε 0.20, O 0.15이며 종합 보상은 100−종합비용이다. A는 보조 지표다. 도달 불가와 충돌은 하드 제약이며 무효 후보를 승자로 선택하지 않는다. 목적별 승자 5개와 종합 승자 1개를 저장하고 동점 정보도 남긴다.

내장 곡선의 1·2차 도함수는 해석적으로 계산한다. L/Kε는 끝점 밀집 기하 격자, 관절 지표는 균일 시간 격자에서 계산한다. 별도 균일 u 격자로 도달·충돌을 추가 검증한다. 관절 미분은 기본 7점 국소 다항 유한차분, 적분은 합성 사다리꼴법을 사용한다.
