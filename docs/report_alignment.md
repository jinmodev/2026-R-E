# 보고서와 프로그램 연결

## 실행

start_app.cmd를 실행한다. 프로젝트 .venv의 Python을 우선 사용한다.
처음 설치할 때에는 다음 선택 의존성이 필요하다.

    .\.venv\Scripts\python.exe -m pip install -e ".[data,analysis,refinement]"
    .\.venv\Scripts\python.exe app.py

시작·도착·팔 길이·장애물 조건을 입력하면 선택한 곡선을 시뮬레이션한다.
보고서 사례 목록에서 P4S000691 또는 P4S000057을 불러올 수 있다.
‘42개 후보 비교’는 같은 입력으로 준비된 후보들을 실제 계산한다. 학습된 추천 모델은 아니다.
조건이 바뀌면 이전 비교 결과와 저장 버튼이 무효화된다.

## 화면

- 수식: 원래 곡선 매개식, 시간법칙, 역기구학 합성식.
- 평가값: 경로 길이 L, 관절 노력도 Eθ, 각가속도 A, 각저크 J, 정칙화 곡률 Kε, 접근 벌점 O.
- 관절각: 기존 애니메이션과 관절각 표시를 유지한다.
- 보고서 식: 익숙한 원형식, 미분·곡률·적분, 교정된 팀원 노트 식.
- 토크·에너지: SI 단위의 모형 가정과 토크·일·손실·검산값.
- 후보 비교: 목적별 승자/동점/미확정 상태와 원자료 묶음 저장.

현재 GUI도 v3 release의 미분기구학·적응형 적분·경로 구간 검사·기하 수렴성 검사를 사용한다.
물리지표가 미확정이더라도 수학적 경로 검사 결과와 구분하여 표시한다.

## 팀원들의 수학적 기여

보고서의 흐름인 ‘극곡선 → 매개방정식 → 미분 → 외적 → 곡률 → 적분’을 화면과 내보내기 식에 반영했다.
위치벡터를 (x,y,0)으로 두면 외적의 크기는 |x′y″−y′x″|이며, 평면 계산에는 이 행렬식으로 충분하다.
시간 t, 진행률 u, 곡선 매개각 φ, 관절각 θ1·θ2를 구분한다.

리마송 원형식 r=a+b cosφ는 반사·회전·이동·등방 확대를 거쳐 입력한 두 끝점에 맞춘다.
원형식의 길이에는 scale, 면적에는 scale², 곡률에는 1/scale을 적용한다.
리마송의 극점은 로봇팔 밑부분과 다르다.

프로그램의 사이클로이드는 xℓ=A(φ−sinφ), yℓ=B(1−cosφ)의 높이 조절 변형이다.
일반적으로 A≠|B|이므로 보통 사이클로이드 길이 8A를 적용하지 않는다.
실제 길이를 반각공식·치환으로 8∫₀¹√(A²+(B²−A²)z²)dz로 바꾸어 검산한다.
극좌표 면적과 사이클로이드 면적은 추가 기하량으로 보존하며 평가점수에는 넣지 않는다.

팀원 노트의 r=a sinφ+b, v=tanφ, cosφ>0인 가지에서는

    x″=(2av³−6av)/(1+v²)³+b(2v²−1)/(1+v²)^(5/2)
    y″=(2a−6av²)/(1+v²)³−3bv/(1+v²)^(5/2)
    κ=|2a²+b²+3abv/√(1+v²)| / (a²+b²+2abv/√(1+v²))^(3/2)

이다. 노트 마지막 벡터에 옮겨 적힌 잘못된 분모를 교정했다.
tan 매개화의 구간·부호 제한이 있으므로 실제 전체 경로 계산은 φ/u를 직접 사용한다.
기존 곡선 생성 함수와 v3 원자료를 이 교정식으로 덮어쓰지 않았다. 기존 생성 함수의 기하 미분은 이미 올바르다.

## 토크와 에너지 모형

보고서의 단일 관절 이상 모형은 교육용 참고식으로 표시한다.

    τ=Iθ̈+mglc cosθ
    ∫τθ̇dt=[Iθ̇²/2+mglc sinθ] at endpoints

cosθ≈1−θ²/2를 사용한다면 적분의 중력항도 mglc(θ−θ³/6)으로 일관되게 바뀌어야 한다.
시작 각속도의 제곱을 빠뜨리지 않으며, 끝점 속도 조건을 명시한다.
위 식의 순 기계적 일은 끝점 상태만으로 결정될 수 있으므로 경로 비교의 에너지 항으로 그대로 쓰지 않았다.

실제 2관절 계산에는

    τ=M(θ)θ̈+C(θ,θ̇)+G(θ)+bθ̇

를 쓴다. θ2는 두 링크 사이 상대각이다.
각 링크의 길이 l, 선밀도 ρ, 질량 m=ρl, 질량중심 c=l/2, 중심 관성 I=ml²/12를 사용한다.

    M11=I1+I2+m1*c1²+m2*(l1²+c2²+2*l1*c2*cosθ2)
    M12=M21=I2+m2*(c2²+l1*c2*cosθ2)
    M22=I2+m2*c2²
    C1=−m2*l1*c2*sinθ2*(2*θ̇1*θ̇2+θ̇2²)
    C2= m2*l1*c2*sinθ2*θ̇1²
    G1=g*((m1*c1+m2*l1)*cosθ1+m2*c2*cos(θ1+θ2))
    G2=g*m2*c2*cos(θ1+θ2)

수평 평면 모드에서는 G=0이다. 중력을 없애도 운동에너지·관성·관절 상호작용은 남는다.

    Pj=τj*θ̇j
    Wnet=∫(P1+P2)dt
    Wpositive=∫(max(P1,0)+max(P2,0))dt
    Wabsorbed=∫(max(−P1,0)+max(−P2,0))dt
    τRMS=√(∫(τ1²+τ2²)dt/T)
    Ecopper=∫R*(τ1²+τ2²)/Kt²dt
    Emodel=Wpositive+Ecopper

Wpositive는 관절별로 계산한다. 한 관절의 음의 전력이 다른 관절의 양의 소비를 상쇄한다고 가정하지 않는다.
Emodel은 회생 회수·기어·모터 구동기 손실·부하·열 변화 등을 생략한 모형 값이며 실측 소비전력은 아니다.
관절 운동 노력도 Eθ=∫(θ̇1²+θ̇2²)dt는 계속 별도 지표로 유지한다.

기본 가정: 수직 평면, 1 unit=0.1 m, ρ=0.35 kg/m, b=0.03 N·m·s/rad,
Kt=0.12 N·m/A, R=0.8 Ω, g=9.80665 m/s². GUI에서 일부 가정을 바꿀 수 있다.
같은 가정과 이동시간 아래에서 후보들을 비교해야 한다.

## 수치 검사

새 물리 계산의 기준은 생성 전에 고정했다.

- 정확한 곡선 미분과 2관절 미분기구학을 사용한다. 유한차분으로 토크를 계산하지 않는다.
- 161/321/641개의 균일 시간 표본에서 물리지표를 계산하고, 641점을 대표값으로 저장한다.
- 321→641 차이가 에너지는 2%, RMS 토크는 1% 이내인지 확인한다. 절대 허용오차 1e-6을 함께 사용한다.
- |Wnet−Δ(K+U)−마찰손실|≤1e-6+0.005*(|Wnet|+|ΔK|+|ΔU|+|마찰손실|)를 확인한다.
- 특이점 또는 실패·비수렴에서는 readiness=false를 남기며 0으로 대체하지 않는다.

위 기준은 유한 격자에 근거한 검사이며 엄밀한 오차 상계는 아니다. 641점은 정확한 참값으로 부르지 않는다.
RMS 토크와 모형 에너지의 사용 가능 여부를 따로 기록한다.
물리 미확정 대안이 있으면 해당 목적의 확정 승자를 만들지 않는다.

## 종합점수 버전

기존 v3 수학 종합점수는 보존한다.
새 report-v4 종합 비용은 거리 .25, 모형 전기에너지 .20, 관절 저크 .20, Kε .20, 접근 벌점 .15이다.
기존 Eθ 항을 명시적 모형 에너지로 교체한 새 점수이며, 데이터를 보고 가중치를 조정하지 않았다.
후보별 min-max 정규화와 후보 개수 차이의 영향을 받는다.
source_balanced_*와 report_balanced_*를 섞어 분석하지 않는다.

## 정제 원자료

권장 전체 생성 명령:

    .\.venv\Scripts\python.exe scripts/build_report_dataset.py --workers 6
    .\.venv\Scripts\python.exe scripts/prepare_report_handoff.py
    .\.venv\Scripts\python.exe scripts/verify_report_dataset.py

단일 처리 또는 작은 개발용 출력:

    .\.venv\Scripts\python.exe scripts/export_report_data.py --output 새폴더
    .\.venv\Scripts\python.exe scripts/export_report_data.py --output 새개발폴더 --limit 4 --no-zip

train 전체 후보를 유지하며 invalid/unresolved를 삭제하지 않는다.
시간 표본은 source selection_valid 후보를 추출하고, 기하 표본은 모든 후보를 추출한다.
CSV.gz와 Parquet를 함께 제공한다. 긴 식은 equations 표로 분리해 반복을 줄였다.
단위·결측 사유·조인 키·표본 격자·가정·분할·버전·출처 해시를 명시한다.
그래프·통계적 우열 분석·최종 포스터·머신러닝 학습은 생성 명령에 포함하지 않는다.
