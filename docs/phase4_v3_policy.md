# Phase 4 v3 파일럿 정책 (실행 전 고정)

- 목적: 검증된 독립 미분·적응형 적분을 **별도 데이터 생성기**에 적용한다.
  기존 GUI, v2 생성기, 원자료, 이전 보고서는 변경하지 않는다. ML은 실행하지 않는다.
- 범위: 이전 선정 규칙으로 정한 train 19개 시나리오, 시나리오당 42개 후보.
  validation/test/challenge의 평가값은 읽지 않는다. 선정 목록·입력 해시를 기록한다.
- 버전: phase4-mathematics-v3-pilot / phase4-v3-generator-v1.
  기본 출력은 data/phase4_v3_pilot이며 비어 있지 않은 폴더는 거부한다.
- Eθ/A/J: differential IK로 미분한다. QUADPACK epsrel=1e-8,
  epsabs=(1e-7,1e-5,1e-3), limit=300. 32개 초기 시간 구간과
  257점 특이점 지수 탐색의 국소 최소 위치를 분할점으로 쓴다.
- QUADPACK의 최종 구간을 32점 Gauss-Legendre 규칙으로 독립 재적분하고,
  노드·실제 시간 가중치·피적분함수를 저장한다. **저장 가중합이 최종 지표**다.
  QUADPACK과 차이는 epsabs+1e-8*abs(reference) 이하이어야 한다.
  경고, 비유한값, 특이점, 구간 재적분 불일치는 미확정으로 남기고 학습 정답으로 승인하지 않는다.
  두 수치법의 일치는 엄밀한 정확도 보증이 아니다.
- 161개 시간표본의 관절 미분 열도 독립 미분으로 갱신하되, 그 격자의 사다리꼴 적분값은
  별도 진단이다. 이를 적응형 요약값과 혼동하지 않는다. 곡선식·theta(t) 합성식은 보존한다.
- L/Kε/O는 이번에 변경하지 않는 v2의 표본 적분이다. 계산법별 버전을 메타데이터에 구분한다.
  특히 O의 추가 수렴성 검증이 없으면 전체 데이터 학습 준비 완료를 주장하지 않는다.
- 도달/충돌: 기존 adaptive_path_check의 16개 초기 구간, 깊이10, 평가한도2049를 유지한다.
  invalid / bounded_clear / unresolved를 구분한다. invalid는 관절 목적 적분을 생략하고 null+이유를 기록한다.
  구간 상계는 고정 팔꿈치 가지·원형 장애물·binary64 모델 가정 아래의 판정이며 안전 인증이 아니다.
- selection_valid는 bounded_clear이고 세 관절 목적 적분이 모두 통과한 후보에 한정한다.
  시나리오에 unresolved 후보가 있으면 승자는 잠정값으로 표시한다. unresolved를 경로 부재로 간주하지 않는다.
- 기존 목적별 정규화·가중치·동점 규칙은 유지한다. A는 기존 종합점수의 구성요소가 아니다.
  후보 42개 중 비교이며 전역 최적이 아니다. 기존 라벨은 덮어쓰지 않고 v2-v3 비교를 따로 저장한다.
- 파일럿 검증: ID/분할/행 수, 42후보·161시간표본, 가중 재적분, 순기구학 복원,
  유효성/라벨 일관성, 전 회귀 테스트, 이전 산출물 해시 보존을 확인한다.
  전체 재생성은 파일럿 결과·시간·미확정률을 보고 다음 단계에서 결정한다.
